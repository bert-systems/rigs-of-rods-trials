What this slice establishes

Slice 04 captured controlled impacts but its 10 m/s matrix exercised parameter changes with no actual strength/removal changes. This slice isolates those missing native paths using pinned dry one-beam fixtures, adds strength-only aggregate events, checks an independent double-precision reference, and shows the signed storage ledger in React.

Energy interpretation

At the current beam length, the rest port is U(new rest/k) − U(old rest/k). Removal subtracts U(new rest/k). These ports explain model storage inventory changes without counting removed storage twice. A strength-only change contributes zero. The native elastic-force channel and correction channel remain separate, so the observed force and midpoint work can be reconstructed.

Lost supported storage is not a measurement of heat, crack formation, particulate energy, sound or material energy dispersal. No newly measured material-fracture energy is claimed. The new gate checks a 0.1 J core closure envelope alongside force, state, work, storage, port, identity and count checks.
